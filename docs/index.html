BEHIND THE PIXELS

More than a collection. A small experiment.

Every game in this collection was created using FLX Engine, a lightweight, open-source 2D game engine built around declarative definitions and JavaScript.

FLX Engine and this collection are personal projects by Ra-Hok, created out of curiosity, experimentation and a love of video games.
